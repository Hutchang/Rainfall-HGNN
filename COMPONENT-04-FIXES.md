## You need to fix: the masks use the DataFrame index, not `order`

`gaugegraphnew.py:189-193` (and the same shape at 194-198, 199-203):

```python
train_mask[
    self.mapping_df["order"][ self.mapping_df["id"].isin(self.train_gauges) ].index.to_list()
] = True
```

It selects `order`, then takes `.index` — so the `order` **values are fetched and thrown
away**. It's using pandas row labels as array positions. `mapping_df.index[...]` gives an
identical result; the `["order"]` does nothing.

That's fine only while label == position. `builder_new.py:27-28` breaks it:

```python
mapping_df = mapping_df[mapping_df["use_in_study"] == True]   # no reset_index()
```

Filtering keeps the original labels and leaves gaps. Reproduced on 8 stations, 2 excluded:

```
index labels : [0, 1, 3, 5, 6, 7]   <- gaps where excluded stations were
order values : [0, 1, 2, 3, 4, 5]   <- what Rule 4 says node order is

mask positions used -> [5, 6, 7]        (from .index)
should have been    -> [3, 4, 5]        (from order)

IndexError: index 6 is out of bounds for axis 0 with size 6
```

**Why it matters:** with 148 eligible of 162, labels run to 161 against a mask of length
148. Anything above 147 raises; anything below is silently the **wrong node**. And
`station_ids` is built from that same mask (`gaugegraphnew.py:245`), so a prediction gets
attributed to the wrong gauge. That is the exact failure Rule 4 of the contract exists to
prevent.

**Fix**, in `builder_new.py` after the filter:

```python
mapping_df = mapping_df[mapping_df["use_in_study"]].reset_index(drop=True)
mapping_df["order"] = range(len(mapping_df))
```

Then in `gaugegraphnew.py`, either drop the misleading `["order"]` and use `.index`
honestly, or use the values: `...["order"][...].to_list()`. Don't leave it as is — it
reads as if it respects `order` and doesn't.

see `tests/data/study/stations_sydney.csv` and its `README.md`. You need three files:

  model a broken gauge measured no rain

  `uv run python -m src.study.split <your config> --seeds config/seeds.yaml`

  swallows the fixture and it never reaches anyone
